# Security Policy

## Reporting a vulnerability

If you find a security problem in YojanaSahay — for example a way to read someone else's data, bypass the admin checks or misuse an API — please **do not open a public GitHub issue**.

E-mail **yojanasahayofficial@gmail.com** with:
- what you found and where (page, API route or file),
- the steps to reproduce it,
- what an attacker could do with it.

We will reply within 3 working days, keep you updated while we fix it, and credit you if you wish once the fix is live.

Please don't access, change or delete other people's data while testing, and give us reasonable time to fix the problem before sharing it publicly.

## Scope

- The website and app at https://yojanasahay.vercel.app
- The Android app (Trusted Web Activity)
- The Telegram bot @YojanaSahayBot
- The source code in this repository
